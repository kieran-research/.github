# Kieran Research

A personal research workspace for building foundations in machine learning, computational science, and reproducible research.

This organization documents the progression from learning core concepts to building experiments, reproducing published work, and eventually conducting original research.

## Research Path

**Foundations → ML Systems → Reproduction → Research Exploration → Original Research**

### Current Stage

Building the foundations required to understand and implement complete machine learning workflows.

## Repositories

- **foundations** — technical notes, mathematics, Python, NumPy, machine learning, PyTorch, and scientific computing.
- **01-first-ml-system** — first complete end-to-end machine learning system.
- Future repositories will contain reproducible experiments, paper reproductions, research probes, and research projects.

## Principles

- Understand before abstracting.
- Keep experiments reproducible.
- Separate learning notes from research artifacts.
- Record failures and negative results.
- Prefer evidence over intuition.
- Keep research outputs inspectable through code, notes, figures, and reports.
